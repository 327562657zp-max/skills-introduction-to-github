# 太阳系·时空 — 4D轨道模拟

一个可在浏览器中交互的太阳系三维轨道可视化。行星在三维空间中沿近似开普勒轨道运行，时间作为第四维连续推进，也可以通过时间轴查看不同日期的行星位置。

## 使用

直接用浏览器打开 `index.html` 即可。页面使用 Three.js ES modules 和 Google Fonts CDN，因此需要联网。若浏览器限制本地模块加载，请在项目目录运行一个静态 HTTP 服务，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 功能

- 太阳与八大行星的实时三维模型，包含行星轨道倾角与偏心率的近似效果。
- 播放/暂停、动画速度选择，以及 2000—2100 年的时间轴。
- 显示或隐藏轨道线与行星运行轨迹。
- 点击行星或右侧图鉴查看简介、轨道距离与公转周期。
- 鼠标拖动旋转视角，滚轮缩放；适配窄屏设备。

行星大小和轨道距离经过视觉压缩，并非真实比例；天文轨道参数为可视化近似值。
